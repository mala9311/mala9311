## Experience

**Data Science & Analytics Intern** · CollegePur · 2026 · 3 months

- Built an end-to-end ETL pipeline in Python that collects college and exam data from CollegeDunia into MongoDB.
- Ran **6 parallel `asyncio` workers** across **7 college sections** for hundreds of colleges, plus a separate crawler over **100+ exam URLs**.
- Engineered an orchestrator with sequential and parallel modes, CLI flags, timeout handling, and run-summary logging.
- Made loads **idempotent with MongoDB upserts**, and added resumable runs, anti-bot handling, and per-run audit logs.
- Fixed concurrency failures by isolating each college in its own browser context and tuning the page-load strategy.
- Handled dynamic React/Next.js pages by navigating the DOM through heading text instead of hashed CSS classes.

`Python` · `Playwright` · `asyncio` · `PyMongo` · `ETL` · `JSON` · `CSV` · `tqdm`
